## このゲームについて（公開向けイメージ）

2人で、**首領側**と**刺客側**のどちらかになって対戦する、短いカードの心理戦です。  
持ち札の枚数と種類は決まっていますが、**どれをいつ出すか**は相手に見えません。  
首領側は有利な構図ですが、刺客側が決着を取れば **マッチポイントが一気に伸びる** ため、一発の読みが試合を決めます。

| 項目 | 内容 |
| --- | --- |
| 人数 | 2人 |
| プレイ時間 | おおよそ5〜8分 |
| ジャンル | カード・心理戦 |

本ゲームは、フィクション作品に登場する類の「非対称な3すくみカード勝負」を、ボドパッ！向けに整理した**非公式**のプレイ版です。公式商品・権利者による提供ではありません。

---

## 勝利条件

**マッチ**（1対局）の勝者は、**マッチポイントを先に2点**取ったプレイヤーです。

| 決着の内容 | マッチポイント |
| --- | --- |
| **首領側**のプレイヤーが、その決着ラウンドに勝った | **+1** |
| **刺客側**のプレイヤーが、その決着ラウンドに勝った | **+2** |

- 表示上は「首領側の勝ち」「刺客側の勝ち」と **どちらの陣営が決着を取ったか** を示し、上表でマッチポイントを加算します（プレイヤーが首領側を担当していても、刺客側の勝ちなら相手に+2）。
- 引き分けのマッチはありません（2点先取）。

### なぜポイントが非対称か（ボドパッ！補完）

原作では首領側が構造的に有利で、刺客側の勝利には大きな見返り（賭け金の倍率など）があります。  
ボドパッ！では賭けではなく **マッチポイント** で同じ緊張感を出します。

- 首領側が押し切るには、決着を **2回** 取る必要がある（1+1=2点）。
- 刺客側は決着 **1回** でマッチポイント2点となり、**相手がまだ0点ならその時点でマッチ勝利**。
- 首領側が先に1点取ったあとでも、刺客側が1回決着を取れば2点で逆転終了（1+2のレースではなく、各プレイヤーが自分の担当側として点を積む）。

**例**

| 経過 | 首領担当の点 | 刺客担当の点 | メモ |
| --- | ---: | ---: | --- |
| 首領側の決着1勝 | 1 | 0 | あと首領1勝でマッチ終了 |
| 続けて刺客側の決着1勝 | 1 | 2 | **刺客担当がマッチ勝利** |
| 刺客側の決着1勝だけ | 0 | 2 | **即マッチ勝利** |

## カードと相性（作品由来のコア）

カードは3種類だけです。勝敗は次の一方通行だけです（三すくみ）。

| カード | 説明 |
| --- | --- |
| **首領** | 首領側だけが1枚持つ |
| **市民** | 双方がそれぞれ4枚ずつ持つ |
| **刺客** | 刺客側だけが1枚持つ |

**相性（強い方がその場の勝ち）**

1. **首領** は **市民** に勝つ  
2. **市民** は **刺客** に勝つ  
3. **刺客** は **首領** に勝つ  

**市民 vs 市民** は **引き分け**（下記）。首領 vs 首領・刺客 vs 刺客は起きません。

## 持ち札

| 側 | 持ち札（合計5枚） |
| --- | --- |
| **首領側** | 首領×1、市民×4 |
| **刺客側** | 刺客×1、市民×4 |

- 手札の**中身**だけ秘匿。残り枚数・捨て札は公開。
- 出したカードは手札に戻さず、**捨て札**に置きます。

---

## 始め方

1. **首領側 / 刺客側** を決めます（未決定: 下記「残りの確認」）。
2. 各自5枚を配ります。オンラインではサーバーが配布し、自分の手札だけ表示します。
3. **決着ラウンド**（以下「ラウンド」）1から開始します。

ローカル（同画面）では、選択中は相手に見えない UI を使います。

---

## 用語

| 用語 | 意味 |
| --- | --- |
| **1手** | 双方が1枚ずつ同時公開する操作 |
| **ラウンド** | 配られた5枚（または残り）を使い、**決着がつくまで**続く区切り。途中の市民引き分けは同じラウンド内 |
| **決着** | 首領・刺客・市民の三すくみで勝敗がついた1手の結果。そのラウンド終了し、マッチポイントを加算 |
| **マッチポイント** | 上表の+1 / +2。先に2点でマッチ勝利 |

---

## 1手の流れ（同時出し）

1. **選択（秘匿）** — 手札から1枚選び **確定**。相手が未確定の間は変更可。**確定後は取り消し不可**（案）。
2. **公開** — 双方が確定したら、同時に表向きにする。
3. **判定**  
   - **市民 vs 市民** → 引き分け。マッチポイントは増えない。出した2枚は捨て札へ。**同じラウンド内**で手順1に戻る。  
   - **それ以外** → 三すくみで勝者が決まる。その勝者が属する **首領側 / 刺客側** で決着。マッチポイントを加算し、**ラウンド終了**。

---

## ラウンドの終わりと次のラウンド

- 決着がついたら、そのラウンドは終了。マッチポイントがどちらか **2点** に達していなければ、**双方に新しく5枚を配り**、次のラウンドを始める（使い残しは持ち越さない）。
- マッチポイントが **2点** に達したプレイヤーがマッチ勝利。残りの配布は行わない。

---

## ゲームの終わり方

- いずれかのプレイヤーのマッチポイントが **2** になった時点でマッチ終了。
- オンラインでは部屋の対局状態が `finished` になる想定。

### 作品由来と補完の整理

- **作品由来:** 首領・市民・刺客の三すくみ、首領側と刺客側の非対称な持ち札（各5枚）、市民同士の引き分け、首領側有利・刺客側の勝利に大きなメリットがある構図。  
- **ボドパッ！補完:** 先後出しではなく同時公開、マッチを「マッチポイント2先取」に整理、メリットを **刺客側決着+2 / 首領側決着+1** で表現、1ラウンドごとに全5枚再配布、オンライン秘匿フロー。

## 残りの確認（オーナー）

1. **役割の決め方** — Aランダム / Bホスト選択 / Cローカル選択・オンラインB / Dその他  
2. **表示名** — カード「首領・市民・刺客」、側「首領側／刺客側」でよいか  
3. **再戦** — マッチごとに首領・刺客を交代するか  
4. **+2/+1** — この倍率感でよいか（代替案: 首領+1のみで刺客は「1決着でマッチ終了」など。現案は「2先取」と「弱者ボーナス」の両立）
