## このゲームについて（公開向けイメージ）

2人で、**首領側**と**刺客側**のどちらかになって対戦する、短いカードの心理戦です。  
持ち札の枚数と種類は決まっていますが、**どれをいつ出すか**は相手に見えません。  
首領側は構造的に有利ですが、刺客側が決着を取ると **得点が大きく伸びる** ため、役割が入れ替わるたびに主導権も変わります。

| 項目 | 内容 |
| --- | --- |
| 人数 | 2人 |
| プレイ時間 | おおよそ8〜15分 |
| ジャンル | カード・心理戦 |

本ゲームは、フィクション作品に登場する類の「非対称な3すくみカード勝負」を、ボドパッ！向けに整理した**非公式**のプレイ版です。公式商品・権利者による提供ではありません。

---

## 勝利条件

各プレイヤーは **個人スコア** を持ちます（初期0）。

**マッチ**（1対局）の勝者は、いつでも **自分のスコア − 相手のスコア ≥ 3** になったプレイヤーです（**3点差先取**）。

### 決着ラウンド後の加点

1回の **決着ラウンド**（三すくみで勝敗がついた区切り）のあと、その決着を取った **陣営** の担当プレイヤーにだけ加点します。

| 決着の勝者（陣営） | 担当プレイヤーのスコア |
| --- | --- |
| **首領側**が決着 | **+1** |
| **刺客側**が決着 | **+2** |

- 市民同士の引き分けでは加点なし（ラウンドは続行）。
- 引き分けのマッチはありません（いずれかが3点差に達するまで続行）。

### 非対称加点の意図（ボドパッ！補完）

原作では首領側が有利で、刺客側の勝利には大きな見返りがあります。  
ボドパッ！では **刺客側の決着を+2** にし、少ない勝ち筋でもスコアレースで追いつけるようにします。

**例（交代なしで簡略）**

| 経過 | A | B | 点差 |
| --- | ---: | ---: | --- |
| 開始 | 0 | 0 | 0 |
| 刺客側の決着でBが+2 | 0 | 2 | B+2 |
| 続けて刺客側の決着でBが+2 | 0 | 4 | **B+4 → B勝利**（≥3） |

首領側だけが決着を取り続ける場合は **+1ずつ** のため、相手が0点なら **3回の首領側決着** で3点差になります。

---

## 首領側・刺客側の交代

- **決着ラウンド**が終わるたびに、内部カウンタを+1します。
- カウンタが **2の倍数** になったタイミング（**2回・4回・6回…** の決着の直後）で、両プレイヤーの **首領側⇔刺客側の担当を入れ替え**ます。
- スコアはそのまま引き継ぎます。交代後はすぐ次のラウンド（新規5枚配布）へ進みます。

市民引き分けだけのラウンドは **決着ラウンドに数えません**（カウンタも進めません）。

---

## 始め方・役割

1. **ホスト**が、マッチ開始前に **自分が首領側で始める / 刺客側で始める** のどちらかを選びます。  
   - ゲストは、もう一方の側になります。  
   - ローカル（同画面）でも同様に、**プレイヤー1をホスト扱い**し、セットアップで側を選びます。
2. 各自5枚を配り、1ラウンド目を開始します。
3. 上記「交代」ルールに従い、決着2回ごとに担当を入れ替えます。

オンラインでは待機画面（`OnlineSetupPanel` 相当）でホストが側を選び、ゲストに表示します。

## カードと相性（作品由来のコア）

カードは3種類だけです。勝敗は次の一方通行だけです（三すくみ）。

| カード | 説明 |
| --- | --- |
| **首領** | 首領側だけが1枚持つ |
| **市民** | 双方がそれぞれ4枚ずつ持つ |
| **刺客** | 刺客側だけが1枚持つ |

**相性（強い方がその手の勝ち）**

1. **首領** は **市民** に勝つ  
2. **市民** は **刺客** に勝つ  
3. **刺客** は **首領** に勝つ  

**市民 vs 市民** は **引き分け**。首領 vs 首領・刺客 vs 刺客は起きません。

## 持ち札

| 側 | 持ち札（合計5枚） |
| --- | --- |
| **首領側** | 首領×1、市民×4 |
| **刺客側** | 刺客×1、市民×4 |

- 手札の**中身**だけ秘匿。残り枚数・捨て札は公開。
- 出したカードは手札に戻さず、**捨て札**に置きます。

---

## 用語

| 用語 | 意味 |
| --- | --- |
| **1手** | 双方が1枚ずつ同時公開する操作 |
| **ラウンド** | 配られた5枚（または残り）を使い、**決着がつくまで**続く区切り。途中の市民引き分けは同じラウンド内 |
| **決着ラウンド** | 三すくみで勝敗がつき、加点と（必要なら）役割交代カウントが進む区切り |
| **スコア** | 各プレイヤーの累計点。+1 / +2 の非対称加点 |

---

## 1手の流れ（同時出し）

1. **選択（秘匿）** — 手札から1枚選び **確定**。相手が未確定の間は変更可。**確定後は取り消し不可**。
2. **公開** — 双方が確定したら、同時に表向きにする。
3. **判定**  
   - **市民 vs 市民** → 引き分け。加点なし。出した2枚は捨て札。**同じラウンド内**で手順1に戻る。  
   - **それ以外** → 三すくみで **首領側 / 刺客側** のどちらが決着したかを決める。担当プレイヤーに加点 → **決着ラウンド終了**。

---

## 決着ラウンドのあと

1. **3点差**を満たしていればマッチ終了。  
2. そうでなければ、**決着ラウンドカウンタ**を+1。2の倍数なら **首領⇔刺客を交代**。  
3. **双方に新しく5枚を配り**、次のラウンドを開始（使い残しなし）。

---

## ゲームの終わり方

- いずれかのプレイヤーが **3点差** に達した時点でマッチ終了。  
- オンラインでは部屋の対局状態が `finished` になる想定。

**再戦**（未実装詳細）：新マッチではスコア0・交代カウンタ0から。ホストが再度側を選択（交代から始めるかは任意ルールにできるが、初版は毎回ホスト選択でよい）。
