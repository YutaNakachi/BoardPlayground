# ココナラ — ヒアリング項目

依頼前・初回メッセージで確認する項目。AGENTS.md の「ルール仕様の整理」に対応する。

## 基本

- ゲームの仮タイトルと世界観（1〜3文）
- 想定人数（例: 2〜4）
- 想定プレイ時間（分）
- 対象年齢・難易度の感覚（カジュアル / 中級 など）

## 遊びの核

- プレイヤーが毎ターン行うこと（1文）
- 勝利条件（最高点、先着、生き残り など）
- 同点時の扱い（共同勝利か、タイブレークか）

## コンポーネント

- カード / ボード / トークン / その他
- 隠し情報の有無（手札を同画面で隠す必要があるか）
- 運の要素（山札、公開ドラフト、完全情報 など）

## 例外

- 山札切れ、置けない、パス可否
- ラウンド数、ゲーム終了トリガー

## 納品・公開

- Board Playground への掲載可否（オリジナルとして公開していいか）
- 希望納期
- 参考にしてほしい雰囲気（既存市販ゲームのルール複製は不可。雰囲気の共有のみ）
