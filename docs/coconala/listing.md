## サービス内容（本文）

```
オリジナルボードゲームのアイデアを、ルールの整理からブラウザで遊べる形にするまでお手伝いします。

アイデアが断片的な段階でも、人数・プレイ時間・勝利条件・手番の流れを一緒に整理し、仕様を明確にしたうえで実装します。

実装したゲームはURLでの納品となります。リンクを開くだけでPC・スマホのブラウザからすぐに遊んでいただけます。

【こんな方に】
・個人で「いつか形にしたい」オリジナルゲームのアイデアがある
・サークルや配信向けに、すぐ試せるデジタル版が欲しい
・将来の物理版を想定し、まずデジタルで試したい

【納品イメージ】
Chrome、Edge、Safariなど一般的なブラウザで遊べるWebアプリとして、URLをお渡しします。「ルールを読むことができ、そのまま同じ画面で交代プレイできる」状態が基本です。
標準としては、制作したゲームをボードゲームの遊び場「ボドパッ！」（https://bodopa.com/）に掲載し、そのページのURLで納品します。
制作するゲームは、同画面での交代プレイが基本となります。ただし、手札など相手の手番中に画面を見せられない秘匿情報があるゲームは、オンライン対戦が可能な状態での納品が前提となります。その分の制作工数が価格に反映されますのでご了承ください。
```

## 購入にあたってのお願い

```
【購入前のご相談をお願いします】
購入前のメッセージで、ルールの複雑度に基づく暫定見積りをお伝えします。これは、仕様のすり合わせで変わる場合がありますので、ご承知おきください。内容にご不明点があれば、その都度ご質問ください。

【ご購入の流れ】
まずは購入前のメッセージでざっくりと内容を確認し、複雑度の合計点と暫定見積りをお伝えします。合意いただけたら、最初に基本25,000円でのご購入をお願いします。（この段階では複雑度の有料オプションは付けません）
その後、ヒアリングを重ね、仕様を確定した後、最終見積りを提示します。見積りの金額に合わせ該当する有料オプションをご購入いただきます。オプション購入完了後、制作に着手する流れとなります。

【納品】
標準は「ボドパッ！」掲載URLです。非掲載はオプションとなります。
納品時は、基本は同画面プレイです。手札など秘匿情報があるゲームは同画面ではお受けできず、オンライン（部屋・秘匿の同期込み）での納品となり、その分の工数は複雑度の見積に含みます。

【実装可否】
仕様確定後に制作に着手し、当方都合で実装・納品が困難な場合は、お支払い済み金額の全額返金のうえ取引キャンセルいたします。整理したルールの仕様書などその時点での副産物は無償でお渡しします。
```

- **【実装可否】**: 任意で「ココナラのキャンセルリクエスト・ご合意が必要」を1句追加可。「仕様書などその時点」→「仕様書など、その時点」と読点を入れてもよい。
- **未記載**（任意）: 暫定より見積が下がった場合は基本25,000円の範囲内で対応。
