# ココナラ — 権利メモ

サービス出品文・取引メッセージに含める要点。

## 基本

- 取り扱うのは依頼者オリジナル、または権利者の許可があるゲームのみ
- 市販ボードゲームのルールを、許可なく再現・移植しない
- ルール文と Web 実装の著作権の帰属は、ココナラの取引条件に加え、納品時に一文で確認する
- ボドパッ！への掲載は依頼者の同意がある場合のみ。掲載時も「オリジナル / 許可あり」の方針に従う
- 秘密情報（未公開の世界観など）は公開ゲームに使わない

## 権利の目安（出品文）

- **オリジナルルールの権利は依頼者に帰属**する想定。運営が依頼者のルールを **無断で商用利用**（出版・商品化のための利用など）しない
- お支払い完了後、依頼者はプレイ・案内・物理版のたたき台としてルールを利用できる想定
- 実装は標準では URL 提供のみ。ソースコードの譲渡は含まない（オプション）
- ボドパッ！掲載時は不特定多数が **プレイできる状態** にする（掲載は依頼者同意前提）。掲載はルールの商用譲渡ではない

## 第三者からの商品化・出版などの問い合わせ

**事前には取次の同意や連絡先は聞かない。**

問い合わせが実際に来たときだけ対応する。

1. お問い合わせフォーム等で受ける（運営宛）
2. 該当ゲームの依頼者に **連絡がつけるか** を確認（ココナラの過去トーク、取引時に分かっている範囲。専用の連絡先リストは持たない）
3. **つく** → 内容を転送する程度（運営は当事者ではない。契約の代理・保証はしない）
4. **つかない** → 問い合わせ側にお断り（権利者への転送はできない）

依頼者のメールを第三者に無断公開しない。転送は依頼者と先方の直接交渉前提。

