# ココナラ — 料金・工数目安

正式な出品価格はココナラ側で設定する。ここでは見積もりのものさしだけ置く。

**複雑度の正式なチェック表・掲載ゲームの見積一覧**: [complexity-checklist.md](./complexity-checklist.md)

**購入〜着手の流れ・購入のお願い文案**: [purchase-flow.md](./purchase-flow.md)

## プラン

| プラン | 目安内容 | 目安工数 |
|---|---|---|
| ライト | 1ラウンド完結、要素が少ないカード／配置 | 数日 |
| スタンダード | 複数ラウンド、ドラフトや同時公開など（**手札秘匿はC1＝別扱い**） | 1〜2週間 |
| フル | 独自ボード、複数フェイズ、例外が多い | 要相談 |

## 加算しやすいもの

- 人数バリエーションごとの例外が多い
- イラスト・テーマアートの制作
- **秘匿情報（C1）**: 同画面不可・**オンライン2人納品必須**。料金は [complexity-checklist.md](./complexity-checklist.md) の **C1（+6）＋7点下限** で表す（秘匿用のオンライン単体オプションはない）
- **オンライン対戦・優先実装（¥100,000）**: **C1なし**向け。同画面URL納品後、盤面公開のオンライン2人を優先キューで追加（納品時必須ではない）

## 含めないもの（初期）

- 既存市販ゲームのルール移植
- 進行のクラウド保存
- C1なし案件の「通常オンライン」は標準納品に含めない（**優先実装オプション**または別途相談）
