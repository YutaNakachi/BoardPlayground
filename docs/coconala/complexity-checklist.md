# 制作代行 — 複雑度チェック表（正式版 v1.2）

ココナラ見積用。基本 **25,000円** ＋ 合計点に応じた上乗せ。プレイ時間は点数に入れない。

## 基本

| 項目 | 内容 |
|------|------|
| 基本料金 | **25,000円** |
| プレイ時間 | **点数に入れない**（メモ用のみ） |
| 運用 | 該当したら加点。迷ったら付けない。 |

## 算定前

| | 内容 |
|---|------|
| お断り | 市販の無許可コピー、「そっくり」 |
| お断り | デッキ構築・長文効果・TCG寄り |
| お断り | チュートリアル必須の設計 |
| 想定カード | トランプ系・種類が少ないカード（**山札枚数は見ない**） |
| 秘匿情報（C1） | **同画面プレイでは受けない**。**オンライン2人納品が必須**。料金は **C1の大きい加点＋合計点** で表す（秘匿用のオンライン単体オプションはない） |

## A. 骨格

| ID | チェック | 点 | コメント |
|----|----------|-----|----------|
| A1 | 3人以上でルールが変わる | +1 | 2人専用と違う扱いがある |
| A2 | 両方のプレイヤーに別系統の勝ち方がある | +1 | 片側だけ複数勝ち方→付けずBで見る |
| A3 | 1手番にフェーズが2つ以上 | +1 | 例：ルーレット→置く、引く→出す |
| A4 | 1手番で意味のある選択が3回以上 | +1 | 毎回「何をするか」を何度も選ぶ |

## B. ルール・盤

| ID | チェック | 点 | コメント |
|----|----------|-----|----------|
| B1 | 例外・特別ルールが5個以上 | +1 | 「ただし」「〜のとき」が多い |
| B2 | 例外・特別ルールが9個以上 | +2 | Bは合計最大+2 |
| B3 | タイブレークが2段階以上 | +1 | 同点時の処理が複数段 |
| B4 | 3ラウンド以上、または終了条件が複数 | +1 | ラウンド制・終了の分岐 |
| B5 | 加点・コンボの系統が3つ以上 | +1 | セット、種類ボーナスなど |
| B6 | 複数ゾーン | +1 | 置き場/コース/ゴール、ホーム辺と核など |
| B7 | 変則盤レイアウト | +1 | 六角、点線盤、十字型すごろく等（矩形だけは0、最大+1） |

## C. カード・情報

| ID | チェック | 点 | コメント |
|----|----------|-----|----------|
| C1 | **秘匿情報あり**（相手の手番中に画面を見せられない等） | **+6** | 同画面不可。納品は **オンライン2人**（部屋・秘匿同期込み）。工数はこの加点に含める |
| C2 | カードの種類数 | 0〜+2 | 効果が違う種類だけ数える（同効果コピーは1種類） |
| | 〜8種類 | 0 | |
| | 9〜16種類 | +1 | |
| | 17〜24種類 | +2 | |
| | 25種類〜 | 要相談 | |
| C4 | 同時公開・秘密の同時選択 | +2 | 一斉に出す、当て合い |
| C5 | 交渉・取引 | +2 | 自由取引フェーズ |

※盤のみのゲームは C2 をスキップ。

## D. 操作・判定

| ID | チェック | 点 | コメント |
|----|----------|-----|----------|
| D1 | 乱数UIが2種類以上 | +1 | サイコロ＋ルーレットなど |
| D2 | 駒・カードの移動が主役 | +1 | 小盤・手数極少は付けない可 |
| D3a | 合法手・勝敗が軽い | 0 | 小さい専用盤・手が少ない |
| D3b | 標準（n連・連結判定など） | +1 | 四目、五目、ヘックスなど |
| D3c | 重い（ポリオミノ・閉じ込め・将棋級） | +2 | ネビュラ・リンク、5五将棋など |
| D5 | 状態が3種類以上常時効く | +1 | 停滞1種だけはBで見る |

※D3は **a/b/cのどれか1つだけ**。

## E. 減点

| ID | チェック | 点 | コメント |
|----|----------|-----|----------|
| E1 | ルール・仕様がほぼ完成 | −1 | 1回だけ |

## 重複・特例

| | 内容 |
|---|------|
| 重複 | B6とD3cが同じならD3優先。C2と枚数は使わない |
| ウサギと猟犬 | **合計2点まで**（25,000 or 45,000）。A2・D2・D5・B+2・D3は付けない |
| ネビュラ・リンク | D3は **c（+2）** 想定 |
| C1あり | 納品は **オンライン2人**。**同画面のみはお断り**。合計点が7点未満でも、上乗せは **7点相当（+60,000）を下限** とする |
| オンライン優先 | **C1なし**の案件のみ。同画面URL納品が前提で、盤面公開のオンラインを **先に** 実装（別オプション） |

## 合計点 → 上乗せ（複雑度のみ）

| 合計点 | 上乗せ | 合計 |
|--------|--------|------|
| 0〜1 | +0 | 25,000 |
| 2〜3 | +20,000 | 45,000 |
| 4〜5 | +40,000 | 65,000 |
| 6〜7 | +60,000 | 85,000 |
| 8〜9 | +80,000 | 105,000 |
| 10〜 | +100,000〜 | 125,000〜 |

**別オプション（複雑度上乗せとは別に加算）**

| オプション | 価格 | いつ付ける |
|------------|------|------------|
| **オンライン対戦・優先実装** | **100,000円** | **C1なし**。同画面で遊べるゲームを作ったあと、**盤面公開のオンライン2人**を優先キューで追加。納品時必須ではない |
| 非掲載URL | 10,000円 | 掲載しない場合 |
| ソースコード譲渡 | 150,000円〜 | 要相談 |
| CPU対戦・優先実装 | 60,000円〜 | C1なし向け。秘匿ゲームは基本非対応 |

**見積の合計** = 25,000 ＋ 複雑度上乗せ（C1ありは **7点未満でも7点扱い**）＋ 任意オプション

※C1（秘匿）と「オンライン優先」は **別物**。秘匿はオンライン必須だが料金は複雑度。優先実装は同画面可能ゲームのおまけ加速。

### 内訳メモ（見直し用）

- **三目並べ**: 通常モードのみなら0点。サイトのローテは B+1 で1点帯内。
- **ウサギと猟犬**: 特例どおり A2・D2・D5・B+2・D3 は付けない。1点（B7のみ）なら25,000も可。
- **ネビュラ・リンク**: 閉じ込め・ポリオミノは D3c。矩形盤のため B7 なし。
- **ルドー**: 十字盤 B7 とゾーン B6 の両方。D3はゴール「ぴったり」等で b。
- **5五将棋**: D3c。千日手は B3。成り・持ち駒は B+2 と D5。
