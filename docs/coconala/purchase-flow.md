# ココナラ — 購入〜着手の流れ

出品・返信の基本フロー。見積は [complexity-checklist.md](./complexity-checklist.md)。

## 流れ

1. **購入前メッセージ** … 複雑度チェック表に基づく **暫定見積**（点数・帯・合計目安）。仕様すり合わせで変わる可能性を伝える。
2. **初回購入** … **基本25,000円のみ**（複雑度オプションは付けない）。
3. **仕様すり合わせ** … メッセージ／ビデオチャットで確定。
4. **確定見積** … 暫定との差分を明示。
5. **オプション追加購入** … トークルームから、確定内容に合う複雑度オプション（＋その他オプション）を追加購入。
6. **着手** … 仕様確定 **かつ** 合意したオプションの追加購入が完了したあと。

## 見積が変わったとき

| 場合 | 対応 |
|------|------|
| 暫定より上がった | 差分に応じたオプションを追加購入してから着手 |
| 暫定と同じ帯 | 該当オプションを追加購入してから着手 |
| 暫定より下がった | **基本25,000円の範囲内で対応**（返金・オプション取り消しはプラットフォーム上期待しない） |

## ココナラ上の注意

- 購入済みオプションの差し替えはできない。追加分は **有料オプションの追加購入** または **おひねり**（合意・購入者操作）。
- 追加決済ごとに購入者側手数料がかかる。オプション名で帯・追加分の意味を誤解されないよう命名する。

## 購入にあたってのお願い（出品文用）

```
【購入前のご相談をお願いします】
購入前のメッセージで、ルールの複雑度に基づく暫定見積（点数の目安・合計の目安）をお伝えします。仕様のすり合わせで変わる場合があります。内容にご不明点があれば、その段階でご質問ください。

【ご購入の流れ】
まずは基本料金25,000円のみでご購入ください（この段階では複雑度の有料オプションは付けません）。
その後、メッセージ／ビデオチャットで仕様をすり合わせ、確定した内容に基づき、改めて合計をご案内します。暫定見積と異なる場合は、該当する複雑度オプション（および必要なその他オプション）をトークルームから追加購入をお願いします。暫定より見積が下がった場合は、基本料金の範囲内で対応します。
実装に着手するのは、仕様の確定と、合意したオプションの追加購入が完了したあとです。

【メッセージで教えてほしいこと】
・ゲームの一言コンセプト（テーマ・雰囲気）
・人数・想定プレイ時間
・勝ち方のイメージ
・参考にしたい雰囲気（市販ゲーム名・作品名は不要）
・NG（表現・ギャンブル要素など）
・利用シーン（個人／配信／企業イベントなど）
・手札など、相手の手番中に画面を見せられない秘匿情報があるか（ある場合は「秘匿あり」と明記）
・ボドパッ！掲載の可否（標準は掲載可）
・希望納期（イベント日は必須）
・予算の上限感
・第三者からの商品化・出版の問い合わせを運営経由で取次してよいか（任意）

【カードがある場合】
山札の枚数ではなく、効果・役割が違うカードの「種類数」を教えてください。

【打ち合わせ】
ココナラのメッセージおよびビデオチャットです。連絡先の直接交換は行いません。

【納品】
標準はボドパッ！掲載URL。非掲載はオプション。納品時は、基本は同画面プレイです。手札など秘匿情報があるゲームは同画面ではお受けできず、オンライン2人（部屋・秘匿の同期込み）での納品となります（料金は複雑度の見積に含みます）。同画面で遊べるゲームについて、盤面が見える2人オンラインを早めに試したい場合は「オンライン対戦・優先実装」オプション（100,000円）をご検討ください（秘匿があるゲームは対象外）。

【実装可否】
仕様確定後に着手し、技術的に困難と判断した場合はお支払いいただきません。詳細はメッセージでご説明します。

【お受けできない例】
市販の無許可なルール再現、「そっくり」系。

【素材】
オリジナルカードアート・イラストは原則お受けしません。
```
