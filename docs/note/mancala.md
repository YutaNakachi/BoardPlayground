# note記事案：マンカラ・カラハ

## 想定読者

短時間で遊べる2人用ゲームを探している人、先を読んで石を動かすゲームが好きな人。

## タイトル案

1. 石をまく一手が次につながる。「マンカラ・カラハ」をブラウザで
2. どの穴から始める？8分で楽しむ石まきゲーム「マンカラ・カラハ」
3. 追加手番と「取り」が勝負を変える、マンカラ・カラハ入門

## リード

穴に入った石を手に取り、反時計回りにひとつずつまいていく。

「マンカラ・カラハ」は、動きはシンプルなのに、最後の1個をどこへ置くかで展開が大きく変わる2人用ゲームです。

## 本文

### 石をまいて、自分のゴールへ

盤には、各プレイヤーの小さな穴が6つと、集めた石を入れるゴールが1つずつあります。最初は小さな穴に4個ずつ、合計48個の石が入っています。

手番で行うことは、自分側の穴をひとつ選ぶだけ。その穴の石をすべて取り、反時計回りに1個ずつ配ります。自分のゴールには入れますが、相手のゴールは飛ばします。

2人用で、プレイ時間の目安は約8分。短い時間でも、石の数を見ながら先を考える楽しさがあります。

### 最後の1個が勝負を決める

大切なのは、まき終わる最後の石です。

最後の石が自分のゴールに入ると、続けてもう一度手番を行えます。うまくつなげれば、相手に手番を渡さず石を集められます。

また、最後の石が自分側の空だった穴に入り、その向かい側に相手の石があれば、それらをまとめて自分のゴールへ移せます。これが「取り」です。

どの穴を選べば追加手番になるか。相手に「取り」の機会を渡さないか。石をまく軽快な動きの中に、数手先を読む駆け引きが隠れています。

### 同じ画面でも、オンラインでも

どちらか一方の小さな穴がすべて空になったら終了です。残った石を持ち主のゴールへ移し、より多く集めたプレイヤーが勝ち。同数なら引き分けです。

ボドパッ！では、同じ端末を囲むローカルプレイに加え、部屋コードを共有するオンライン対戦にも対応しています。

詳しい手順は **[マンカラ・カラハのルールページ](https://bodopa.com/games/mancala)** へ。対戦するときは **[マンカラ・カラハを遊ぶ](https://bodopa.com/play/mancala)** から始められます。

## 締め

石をひとつずつまく、心地よいリズム。その最後に待つ追加手番や「取り」を狙って、8分ほどの読み合いを楽しんでみてください。
