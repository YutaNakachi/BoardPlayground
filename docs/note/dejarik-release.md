## 本文

### どんなゲーム？

外輪・中輪・中央の合計28マスがある円形の盤です。各プレイヤーはブルート・プレデター・ガーディアン・スカウトの4タイプを1体ずつ持ち、後攻から交互にホーム半円へ配置してから、先攻から手番を進めます。

勝ち方はシンプルで、相手の4体をすべて除去すれば勝利です。自分が1体だけになったあとは、3手以内に相手を1体取れなければ負けという緊迫ルールもあり、終盤まで読みが続きます。目安のプレイ時間はおおよそ10分です。

### 型ごとの動きが戦いの主役

ブルートは斜め移動や外輪のワープ、プレデターは飛び越えのあるL字、ガーディアンは守りの厚い横攻撃、スカウトは同一手番での移動と攻撃の組み合わせなど、4タイプそれぞれに個性があります。どの型を前に出し、どこから攻めるか——短い対局でも配置と手順の選択が楽しめます。

### 遊び方（ボドパッ！版）

同じ画面を囲む**ローカルプレイ**に加え、**オンライン対戦**（2人）と**CPU対戦**（弱・普通・強）にも対応しています。ルールの細部や非公式であることの説明は **[デジャリックのルールページ](https://bodopa.com/games/dejarik)** にまとめています。すぐ指す場合は **[デジャリックを遊ぶ](https://bodopa.com/play/dejarik)** からどうぞ。
