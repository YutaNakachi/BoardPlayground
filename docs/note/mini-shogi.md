# note記事案：5五将棋

## 想定読者

将棋の駒を使った短時間の対局を楽しみたい人、持ち駒や成りを生かすゲームが好きな人。

## タイトル案

1. 5×5盤に将棋の攻防を凝縮。「5五将棋」をブラウザで
2. 小さな盤ほど、玉が近い。「5五将棋」を遊んでみよう
3. 持ち駒も成りも楽しめる、約15分の「5五将棋」

## リード

盤は5×5。でも、取った駒を打ち、敵陣で成り、玉を追い詰める将棋の魅力はしっかり残っています。

「5五将棋」は、小さな盤で展開の速い攻防を楽しめる2人用ゲームです。

## 本文

### 5×5に凝縮された将棋

5五将棋で使う盤は、本将棋より小さい5×5。駒は玉・金・銀・角・飛・歩を使い、桂馬と香車は登場しません。先手と後手は点対称に駒を並べて対局を始めます。

人数は2人、プレイ時間の目安は約15分です。盤が小さいぶん、序盤から相手の玉との距離が近く、一手ごとの影響がすぐ盤面全体へ広がります。

### 取った駒を、もう一度使う

手番では、自分の駒をひとつ動かすか、持ち駒を空いているマスへ打ちます。相手から取った駒を自分の戦力として使えるため、盤上の駒が減っても攻めの可能性は減りません。

相手の玉へ迫るために打つか、自分の守りを補うために打つか。5×5の盤では逃げ道も限られるため、持ち駒を使う場所が大きな意味を持ちます。

### 敵陣の最奥で「成る」

銀・角・飛・歩は、敵陣の最奥1段へ入るとき、またはそこから出るときに成れます。歩が最奥段へ入った場合は、必ず「と」になります。

角は竜馬、飛は竜王となって動ける方向が増えます。盤が小さいからこそ、成った駒の影響力は強力です。一方で、同じ筋に未成りの歩を2つ置く「二歩」や、最奥段への歩打ちはできません。

勝利条件は、相手の玉を詰ますか、玉を取ること。ボドパッ！版では同じ局面が4回現れた場合、千日手として後手の勝ちになります。

現在は、同じ画面を囲んで交代するローカルプレイに対応しています。初期配置や駒の動きは **[5五将棋のルールページ](https://bodopa.com/games/mini-shogi)** で確認できます。対局するときは **[5五将棋を遊ぶ](https://bodopa.com/play/mini-shogi)** へどうぞ。

## 締め

盤が小さいからこそ、一手の攻めと守りが濃くなる5五将棋。持ち駒と成りを使って、相手の玉へ続く道を組み立ててみてください。
