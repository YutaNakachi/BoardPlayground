# note記事案：ヘックス

## 想定読者

運に左右されない2人用ゲームが好きな人、シンプルなルールでじっくり考えたい人。

## タイトル案

1. 向かい合う2辺をつなげ。「ヘックス」をブラウザで遊ぼう
2. 置くだけなのに、道は簡単につながらない――2人用ゲーム「ヘックス」
3. 引き分けなし。六角形の盤で競う接続ゲーム「ヘックス」

## リード

自分の石で、向かい合う2辺をつなげたら勝ち。

「ヘックス」は、このひとつの目標をめぐって道を作り、相手の道を阻む2人用の戦略ゲームです。サイコロもカードもなく、勝負を決めるのは石を置く場所だけです。

## 本文

### 自分の色で、端から端へ

ボドパッ！版の盤は、六角形のマスを菱形に並べた11×11。空いているマスへ、2人が交互に石を1個ずつ置きます。一度置いた石を動かすことはできません。

赤の目標は上辺と下辺、青の目標は左辺と右辺をつなぐこと。隣り合う自分の石をたどって、担当する2辺の間に途切れない道ができれば勝ちです。

プレイ時間の目安は約15分。ルールは短いものの、盤全体を見ながら考える必要がある、じっくり型のゲームです。

### 相手を止める手が、自分の道にもなる

自分の道をまっすぐ伸ばすだけでは、相手に先回りされるかもしれません。逆に、相手の進路をふさぐことばかり考えると、自分の道が遠回りになります。

六角形のマスは最大6方向につながります。そのため、一本の線を作るというより、複数の候補を残しながら網のように道を広げるのがポイントです。

ヘックスには引き分けがありません。盤が埋まった場合でも、必ずどちらか一方の道が完成します。最後まで勝敗が決まるのも、このゲームの特徴です。

### 先手と後手の差を調整するスワップ

先手が最初の石を置いた直後、後手はそのまま2手目を置くか、最初の石を自分の色にして担当を入れ替える「スワップ」を選べます。

先手は、強すぎず弱すぎない初手をどこへ置くか。後手は、その初手を受け取る価値があるか。この選択から、すでに対局は始まっています。

ボドパッ！ではローカルプレイとオンライン対戦に対応しています。詳しい接続方向やスワップの手順は **[ヘックスのルールページ](https://bodopa.com/games/hex)** へ。対局は **[ヘックスを遊ぶ](https://bodopa.com/play/hex)** から始められます。

## 締め

ひとつ置くたびに、道の候補が増えたり消えたりするヘックス。自分の道をつなぎ切る一手を、11×11の盤から見つけてみてください。
