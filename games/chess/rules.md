# チェス

## このゲームについて

8×8の盤で駒を動かし、相手のキングを詰める2人用の抽象戦略ゲームです。

| 項目 | 内容 |
|---|---|
| 人数 | 2人 |
| プレイ時間 | おおよそ20〜60分 |
| ジャンル | 盤面・抽象戦略 |

## 勝利条件

相手のキングを**チェックメイト**（王手のまま合法手がなくなる状態）にしたプレイヤーが勝ちです。

チェックではないのに合法手がなくなった場合は**ステイルメイト**となり、引き分けです。

## 盤面の構成

- 8×8 のマス目
- 各プレイヤーの駒：キング1、クイーン1、ルーク2、ビショップ2、ナイト2、ポーン8
- プレイヤー1（白）：手前（下段）
- プレイヤー2（黒）：奥（上段）

## 始め方

標準的な初期配置で駒を並べ、プレイヤー1（白）から手番を始めます。

## 手番の流れ

1手につき、自分の駒を1つ選び、合法な移動先へ動かします。

### 各駒の動き

| 駒 | 動き方 |
|---|---|
| キング | 周囲8方向に1マス |
| クイーン | 縦・横・斜めに何マスでも |
| ルーク | 縦・横に何マスでも |
| ビショップ | 斜めに何マスでも |
| ナイト | L字（他の駒を飛び越えられる） |
| ポーン | 前方1マス（初手のみ2マス可）。斜め前方の相手駒を取れる |

### 特殊な手

- **キャスリング**：キングとルークがまだ動いておらず、その間のマスが空いている場合、キングを横に2マス動かし、ルークを取る手
- **アンパッサン**：相手のポーンが2マス進んだ直後、隣の自分のポーンが斜めの通過マスを取れる手
- **昇格**：ポーンが最奥段に到達したら、自動的にクイーンになります

### 王手について

自分のキングがチェック（王手）にさらされる手は選べません。

## ゲームの終わり方

- **チェックメイト**：相手のキングが王手で、合法手がない → 勝利
- **ステイルメイト**：王手ではないが合法手がない → 引き分け

## このサイト版の補足

- 50手ルール・3回繰り返しなどの引き分け条件は採用していません。
- ポーンの昇格はクイーンのみ（自動）です。
- 王手放置・タッチムーブなどの競技用の細則は採用していません。
