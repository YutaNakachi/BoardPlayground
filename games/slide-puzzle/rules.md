# スライドパズル

## このゲームについて

3×3〜6×6の盤（開始前に選べます）で、1から（マス数−1）の数字タイルを順番に並べる1人用パズルです。空きマスを使ってタイルをスライドさせます。

| 項目 | 内容 |
|---|---|
| 人数 | 1人 |
| プレイ時間 | おおよそ5分 |
| ジャンル | パズル |

## 勝利条件

次の状態になれば完成（クリア）です。

- 左上から 1, 2, 3 …（最後の数字）の順に並んでいる
- 右下のマスが空き

## 盤面の構成

- 3×3 / 4×4 / 5×5 / 6×6 のマス目（1マスは常に空き）
- タイル：1〜（マス数−1）

## 始め方

必ず**解ける配置**にシャッフルして開始します（完成状態からは始まりません）。

## 手番の流れ

1. 空きマスに上下左右で隣接しているタイルをタップします。
2. タップしたタイルが空きマスへ1マススライドします。
3. 1タップで1手です。

## ゲームの終わり方

1から最後の数字までが順に並び、右下が空きになったら完成です。手数の上限はありません。

## このサイト版の補足

- 最初から完成できない並びにはしません。
- やり直し（リプレイ）で、新しいシャッフルから再開できます。

## 実装

Web 版は `components/play/SlidePuzzleGame.tsx`。盤面ロジックは `lib/play/slide-puzzle.ts`。
