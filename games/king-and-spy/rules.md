# キング＆スパイ（仮）

## このゲームについて

2人で、**首領側**と**刺客側**のどちらかになって対戦する、短いカードの心理戦です。  
持ち札の枚数と種類は決まっていますが、**どれをいつ出すか**は相手に見えません。

| 項目 | 内容 |
| --- | --- |
| 人数 | 2人 |
| プレイ時間 | おおよそ8〜15分 |
| ジャンル | カード・心理戦 |

フィクション作品に登場する類の「非対称な三すくみカード勝負」を、ボドパッ！向けに整理した**非公式**のプレイ版です。公式商品・権利者による提供ではありません。

## 勝利条件

各プレイヤーは **個人スコア**（0から）を持ちます。  
**自分のスコア − 相手のスコア ≥ 3** になったプレイヤーがマッチに勝ちます。

決着ラウンドのあと、決着を取った **陣営の担当プレイヤー** に点数が入ります。

| 決着の勝者（陣営） | 加点 |
| --- | --- |
| 首領側 | +1 |
| 刺客側 | +2 |

点数は **プレイヤー個人** に付きます。首領側・刺客側の**担当は、決着2回ごとに入れ替わり**ます（スコアは引き継ぎ）。

## カードと相性

| カード | 持ち方 |
| --- | --- |
| 首領 | 首領側だけが1枚 |
| 市民 | 双方が4枚ずつ |
| 刺客 | 刺客側だけが1枚 |

**相性（強い方がその手の勝ち）**

1. 首領 は 市民 に勝つ  
2. 市民 は 刺客 に勝つ  
3. 刺客 は 首領 に勝つ  

**市民 vs 市民** は引き分けです（加点なし・同じラウンド内で続行）。

## 1ラウンドの流れ

1. 双方に5枚を配ります。  
2. 手札から1枚を選び **確定**します（相手の確定前は変更可。確定後は取り消し不可）。  
3. 双方が確定したら **同時に公開**します。  
4. 市民同士なら捨て札に置き、手順2へ。それ以外なら決着・加点し、ラウンド終了。  
5. マッチが続く場合は新しく5枚を配ります。

## 担当の入れ替え

**決着ラウンド**（加点が発生した区切り）が **2回・4回・6回…** 終わった直後に、首領側と刺客側の担当を入れ替えます。

## 始め方

- **ローカル（同画面）**: プレイヤー1がホスト扱い。開始前にプレイヤー1が首領側または刺客側で始めるかを選びます。  
- **オンライン**: ホストが待機画面で自分の開始側を選び、2人揃ってから開始します。

## このサイト版の補完

- 原作に近い **各5枚** の持ち札と三すくみ・市民引き分けを採用しています。  
- 出し方は **同時確定・同時公開**（先後出しは採用しません）。  
- 勝利は **点差3点**、刺客側決着の加点 **+2**、**2決着ごとの担当交代** はボドパッ！版の整理です。  
- オンライン対戦では手札は相手に見えません（部屋コード・非公式）。
