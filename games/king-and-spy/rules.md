# キング＆スパイ

## このゲームについて

2人で、**キング**と**スパイ**のどちらかの役になって対戦する、短いカードの心理戦です。  
持ち札の枚数と種類は決まっていますが、**どれをいつ出すか**は相手に見えません。

| 項目 | 内容 |
| --- | --- |
| 人数 | 2人 |
| プレイ時間 | おおよそ8〜15分 |
| ジャンル | カード・心理戦 |

漫画『カイジ』に登場する **Eカード** をモチーフに、ボドパッ！向けに整理した**非公式**のプレイ版です。公式商品・権利者による提供ではありません。

## 勝利条件

各プレイヤーは **個人スコア**（0から）を持ちます。

- **自分のスコア − 相手のスコア ≥ 3** になったプレイヤーがマッチに勝ちます。  
- または **12ラウンド**（決着ごとに数える）までに点差3に達しなかった場合、**その時点で得点が高いプレイヤー**の勝ちです（同点なら引き分け）。

決着ラウンドのあと、決着を取った **陣営の担当プレイヤー** に点数が入ります。

| 決着の勝者（陣営） | 加点 |
| --- | --- |
| キング側 | +1 |
| スパイ側 | +2 |

点数は **プレイヤー個人** に付きます。キング／スパイの**担当は、決着2回ごとに入れ替わり**ます（スコアは引き継ぎ）。12ラウンドまでプレイした場合、各プレイヤーはキング担当・スパイ担当がそれぞれ **6ラウンドずつ** になります（交代ルールによる）。

## カードと相性

| カード（表示） | 持ち方 |
| --- | --- |
| キング | キング側だけが1枚 |
| 市民 | 双方が4枚ずつ |
| スパイ | スパイ側だけが1枚 |

**相性（強い方がその手の勝ち）**

1. キング は 市民 に勝つ  
2. 市民 は スパイ に勝つ  
3. スパイ は キング に勝つ  

**市民 vs 市民** は引き分けです（加点なし・同じラウンド内で続行）。

## 1ラウンドの流れ

1. 双方に5枚を配ります（画面上で **ラウンド n / 12** を表示）。  
2. 手札から1枚を選び **確定**します（相手の確定前は変更可。確定後は取り消し不可）。選んだカードは **先に裏向きで場に出てから** 手札から消えます。両者のカードが場に揃っても、**両者の手札減らしが終わるまでは公開しません**。  
3. 公開して結果を示してから、手札と得点を更新します。市民同士なら加点なしで、手札は減ったまま同じラウンドを続行します。それ以外なら決着・加点し、そのラウンドは終了します。  
4. マッチが続く場合、決着のあとの手札は5枚に戻します。引き分けのあとは戻しません。

## 担当の入れ替え

**決着**（加点が発生した区切り）が **2回・4回・6回…** 終わった直後に、キング側とスパイ側の担当を入れ替えます。

## 始め方

- **ローカル（同画面）**: プレイヤー1がホスト扱い。開始前にプレイヤー1がキング側またはスパイ側で始めるかを選びます。  
- **オンライン**: ホストが待機画面で自分の開始側を選び、2人揃ってから開始します。

## このサイト版の補完

- 『カイジ』のEカードに近い **各5枚** の持ち札と三すくみ・市民引き分けを採用しています。  
- 出し方は **同時確定・裏向きで場に出す・同時公開**。  
- 勝利は **点差3点** または **上限12ラウンド**、スパイ側決着の加点 **+2**、**2決着ごとの担当交代** はボドパッ！版の整理です。  
- オンライン対戦では手札は相手に見えません（部屋コード・非公式）。本番 Supabase には `room_secrets` 用マイグレーション（`008_room_secrets.sql`）の適用が必要です。
