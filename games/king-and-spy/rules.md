# キング＆スパイ

## このゲームについて

漫画『賭博黙示録カイジ』に登場する **Eカード** をモチーフにした、2人用のカード心理戦です。  
**キング**側と**スパイ**側に分かれ、手札から1枚ずつ出します。持ち札の中身は相手に見えません。

| 項目 | 内容 |
| --- | --- |
| 人数 | 2人 |
| プレイ時間 | 目安10分 |
| ジャンル | カード・心理戦 |

## 勝利条件

各プレイヤーは、0点から始まる得点を持ちます。

- 自分の得点が相手より **3点以上** 高くなったプレイヤーの勝ちです。
- **12ラウンド** が終わっても点差が3点未満なら、得点が高いプレイヤーの勝ちです。同点のときは引き分けです。

ラウンドは、決着がついた回数で数えます。市民同士の引き分けは、同じラウンドの続きです。

決着がついたとき、勝った側を担当しているプレイヤーに点が入ります。

| 勝った側 | 加点 |
| --- | --- |
| キング側 | +1 |
| スパイ側 | +2 |

点はプレイヤー個人に付きます。キング側とスパイ側の担当は、決着2回ごとに入れ替わります。得点はそのままです。12ラウンドまで進んだ場合は、この交代により、キング側とスパイ側を6ラウンドずつ担当します。

## カードと相性

| カード | 枚数 |
| --- | --- |
| キング | キング側だけが1枚 |
| 市民 | 双方が4枚ずつ |
| スパイ | スパイ側だけが1枚 |

強い方が、その1回の勝ちです。

1. キングは市民に勝ちます。
2. 市民はスパイに勝ちます。
3. スパイはキングに勝ちます。

市民同士は引き分けです。加点はなく、同じラウンドを続けます。

## 1ラウンドの流れ

1. 双方に5枚を配ります。画面には **ラウンド n / 12** と出ます。
2. 手札から1枚を選び、**確定**します。相手が確定する前なら選び直せます。確定したあとは取り消せません。
3. 選んだカードは、先に裏向きで場に出ます。そのあと、そのカードが手札から消えます。
4. 両者のカードが場に揃っても、両者の手札からカードが消えるまでは公開しません。
5. 公開して結果を示してから、手札と得点を更新します。市民同士なら加点はなく、手札は減ったまま同じラウンドを続けます。それ以外は決着になり、点を加えてそのラウンドは終わります。
6. 決着のあと、マッチが続くときは手札を5枚に戻します。引き分けのあとは戻しません。

## 担当の入れ替え

加点のあった決着が **2回、4回、6回…** 終わった直後に、キング側とスパイ側の担当を入れ替えます。

## 始め方

- **ローカル（同じ画面）**: プレイヤー1が先に操作します。開始前に、プレイヤー1がキング側とスパイ側のどちらで始めるかを選びます。
- **オンライン**: ホストが待機画面で自分の開始側を選び、2人そろってから始めます。

## 作品由来と、このサイトで足したルール

**作品由来**

- 漫画『賭博黙示録カイジ』のEカードにならい、各5枚（主役のカード1枚と市民4枚）の持ち札にしています。
- 三すくみと、市民同士の引き分けは、作品の勝負の形に沿っています。

**ボドパッ！版で足したルール**

- 勝敗は、点差3点、または12ラウンドで決めます。
- キング側の決着は+1点、スパイ側の決着は+2点です。
- 決着2回ごとに、キング側とスパイ側の担当を入れ替えます。
- カードは同時に1枚ずつ確定し、裏向きで場に出します。両者の手札からカードが消えてから、同時に公開します。

オンラインでは、相手から手札は見えません。

## 実装

Web版は `components/play/KingAndSpyGame.tsx`。ロジックは `lib/play/king-and-spy/`。  
オンラインの手札は相手に送らず、`room_secrets` に置きます。本番の Supabase には、マイグレーション `008_room_secrets.sql` の適用が必要です。
