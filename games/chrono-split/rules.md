# クロノ・スプリット

## このゲームについて

過去・現在・未来のカードをタイムラインに並べ、点数とボーナスで得点を競う、2〜4人用のオリジナル配置ゲームです。

| 項目 | 内容 |
|---|---|
| 人数 | 2〜4人 |
| プレイ時間 | おおよそ8分 |
| ジャンル | カード・配置 |

## 勝利条件

ゲーム終了時の得点が最も高いプレイヤーが勝ちです。同点の場合は引き分け（共同勝利）です。

## 用意するもの

- カード24枚：過去・現在・未来の3時代 × 点数1〜4 × 各2枚
- **場**：常に最大3枚のカードが公開されます
- **タイムライン**：各プレイヤーが左から右へ5枠を持ちます

## 始め方

1. 24枚をよく混ぜます。
2. 場に3枚を表向きに置きます。
3. 各プレイヤーのタイムラインは空です。
4. プレイヤー1から手番を始めます。

## 手番の流れ

1手につき、次の操作を行います。

1. 場の公開カードから1枚選びます。
2. 自分のタイムラインの空いている枠のどれかに置きます。
3. 山札にカードが残っていれば1枚めくり、場が3枚になるまで補充します。

パスはできません。空き枠がある限り、必ず1枚取って置きます。

## 得点の計算

全員のタイムラインが5枠埋まったら得点を計算します。

1. **基本点**：置いたカードの点数の合計
2. **時代の共鳴**：隣り合う枠が同じ時代なら、その組ごとに +2点（3枚連続なら組は2つ）
3. **3時代ボーナス**：タイムラインに過去・現在・未来がすべて揃っている → +3点
4. **時系列ボーナス**：左から右へ、隣り合うカードの点数が常に「左 ＜ 右」 → +7点

時系列ボーナスは「以上」ではなく**厳密な増加**です。同じ点数が隣り合うと不成立になります。

## ゲームの終わり方

全員のタイムラインが5枠埋まったら終了し、得点で勝敗を決めます。

## このサイト版の補足

- 山札が尽きても、場にカードが残っていればそこから取り続けられます。
- 同点のとき、追加の判定は行いません。
