# デジャリック

## このゲームについて

円形のホロ盤で、型の異なる **クリーチャー** を動かし、相手のクリーチャーをすべて除去する **2人用** の対戦ゲームです。SF 作品に登場する「円盤のホロ戦棋」を、ブラウザで遊べる **フィクション** として再現した **ボドパッ！独自の非公式** ルールです。

| 項目 | 内容 |
|---|---|
| 人数 | 2人 |
| プレイ時間 | 目安 15〜25 分 |
| ジャンル | 盤面・抽象戦 |

> **非公式**: 本ページのルールはボドパッ！による解釈であり、公式商品・権利者による提供ではありません。

---

## 作品に見えるところ（フィクション上のイメージ）

- 2人が向かい合い、**円形のチェック盤** の上でホロの **クリーチャー** が戦う。
- 手番でクリーチャーを動かし、相手を **マスに乗って** 取り除く。
- 盤の中央付近や外周で、思い切りの移動・奇襲が起きる。

作品そのものでは手順の細部は語られていないため、以下は **ボドパッ！版** として定めます。

---

## 参考にした考え方（表現のみ）

市販の円形盤ゲームで流通している方式を参考に、次の骨格を採用しています（文言・数値のコピーはしていません）。

- **攻撃は、攻撃パターンに沿って相手のいるマスへ入り、相手を除去する**（そのマスに自分が残る）。
- 1ターンの基本は **「移動」か「攻撃」のどちらか一方**（スカウトのみ例外）。
- 盤は **外輪・中輪・中央** の円形レイアウト。

移動パターン・スカウトの二動作・ブルートのワープなどは、ボドパッ！版の独自定義です。

---

## 勝利条件

相手のクリーチャー **4体すべて** を除去したプレイヤーが勝ちです。引き分けはありません。

## 盤面

### マスの構造

- **外輪** 12マス、**中輪** 12マス、**中央** **4マス**。合計 **28マス**。
- 外輪と中輪は、これまでどおり **12本のレイ** で対応する（外輪マス `O0`〜`O11` と中輪マス `M0`〜`M11` が同じレイ）。
- **中央は中輪の内側（盤の芯側）** に並ぶ **もう一段の輪** として扱う。外輪・中輪と同様、**通常のマス**（進入・停止・戦闘の対象になる）。

#### 中央4マスと中輪のつながり

中輪12マスを **連続3マスずつ4組** に分け、各組に **中央マス1つ** が対応する。

| 中央マス | 接続する中輪マス（3マス） |
|---|---|
| `C0` | `M0`, `M1`, `M2` |
| `C1` | `M3`, `M4`, `M5` |
| `C2` | `M6`, `M7`, `M8` |
| `C3` | `M9`, `M10`, `M11` |

**1つの中央マスは、ちょうど3つの中輪マスと隣接**する（逆に、各中輪マスは **外輪1マス** と **中央1マス** の2方向にレイでつながる）。

中央4マス同士は **内輪** として `C0`—`C1`—`C2`—`C3`—`C0` の **4マス輪** で隣接する（周回方向に ±1）。

```
        外輪 12（O0…O11）
           ‖ 各レイ
        中輪 12（M0…M11）
          ╲│╱  3本ずつ1つの C に接続
        中央 4（C0…C3）※内側の輪
```

### 隣接（**縦横**）

次のいずれかで隣り合うマス同士を **縦横1マス** とする。

| 場所 | 縦横のつながり |
|---|---|
| 外輪・中輪 | 同じ輪上でインデックス ±1（12で一周）。同じレイで外輪 ↔ 中輪 |
| 中輪 ↔ 中央 | 上表の対応（例: `M4` は `O4`・`C1` とレイ方向に隣接） |
| 中央4マス | 内輪の `C±1`（4で一周） |

**斜め**（ブルートのみ）とは、**縦横1マス分の移動を2回分の直交成分として同時に行った先**（例: 外輪から中輪へ入りつつ輪方向に ±1）。クリーチャーは中心を向くので、**斜め前** は中心寄り、**斜め後** は外周寄りの成分を含む斜めとして扱う（詳細はブルートの項）。

### 向き（「前」「後」「横」）

各プレイヤーは盤の **向かい側** に座り、どちらのプレイヤーのクリーチャーも常に **盤の中心（内側）** を向いて配置される（向きは回転しない）。

#### 外輪・中輪にいるとき

| 方向 | 意味 |
|---|---|
| **前** | **レイ上**で **中心側へ** 1マス（外輪 → 中輪、中輪 → その中輪が接続する **中央マス**） |
| **後** | **レイ上**で **外周側へ** 1マス（中輪 → 外輪。外輪からさらに外へ出る扱いはブルートのワープなど別ルール） |
| **横** | いまいる **12マス輪** 上の周回方向（左右どちらか）。レイ方向の前・後とは別 |

輪上の「前」に相当する **相手ホームへ近づく周回** は、外輪・中輪では **横** の選択肢の一部として UI で示す（プレデターのジャンプなどで使う）。

#### 中央マスにいるとき

中央はすでに最も内側なので、**前は存在しない**。

| 方向 | 意味 |
|---|---|
| **前** | **なし**（使えない） |
| **後** | その中央マスに接続する **中輪3マスのいずれか** へ1マス（**3通りから選ぶ**） |
| **横** | **隣接する中央マス** へ1マス（内輪 `C0`—`C1`—`C2`—`C3`—`C0` の ±1。**中輪の周回ではない**） |

例: `C1` にいるとき、**後** は `M3` / `M4` / `M5` のいずれか。**横** は `C0` または `C2` のみ。

### ホーム半円

- 外輪 12マスのうち、各プレイヤーに **連続する 6マス** をホーム半円とする（向かい合う配置）。
- 初期配置は、自分のホーム半円のうち **連続する 4マス** のみを使う。

---

## クリーチャー（4型）

各プレイヤーは次の **4体** を持つ。コマの種類は **型** だけで表し、個別の生物名は使いません。

| 型 | 役割イメージ |
|---|---|
| **ブルート** | 重戦車。近距離の全方位とワープ。 |
| **プレデター** | 奇襲。L字の飛び越え移動。 |
| **ガーディアン** | 防衛。横に広がり、遠めのマスへ飛び込んで攻撃。 |
| **スカウト** | 高速偵察。直線2マス、1ターンで移動と攻撃。 |

---

## 共通ルール

### 占有

- **味方のいるマスには入れない**（移動・攻撃の終点になれない）。
- **相手のいるマス** には、**攻撃** のときだけ終点にできる（取り除く）。

### 通過

- 移動経路上に他のクリーチャーがあるマスは、**通過できない**（止まることもできない）。
- **例外**: **プレデター** の移動・攻撃では、**経路上のマスを飛び越えられる**（終点以外のマスにいる駒の上を通れる）。

### 攻撃（全型共通）

- 攻撃は **攻撃パターンで相手がいるマスへ入り**、その相手を除去する。自分はそのマスに残る。
- 攻撃パターンの距離・形は型ごとに定める。途中マスに駒があると通過できない（プレデターの飛び越えは移動・攻撃の経路に適用）。
- **まだ動いていない相手への制限はない**（ボドパッ！版では採用しない）。

### 1ターンの手番

| 型 | そのターンにできること |
|---|---|
| ブルート・プレデター・ガーディアン | **移動** または **攻撃** の **どちらか1つ** |
| スカウト | **移動**、**攻撃**、または **両方**（順序は自由）。どちらか一方だけでもよい。 |

## 型ごとの移動・攻撃

### ブルート

1ターンに **移動** または **攻撃** のどちらか一方（どちらも **1マス**）。

**移動・攻撃（1マス）**: いまいるマスから **縦横1マス** または **斜め1マス** のいずれかへ進む。終点に相手がいれば **攻撃**（入って除去）、空なら **移動**。斜めは **ブルートだけ** が使える。

#### 1マスで行ける先（輪ごと）

**外輪**（例: `O4`）

| 種類 | 行き先 |
|---|---|
| **縦横・前** | レイ: `M4` |
| **縦横・横** | 周回: `O3`, `O5` |
| **斜め前** | 中輪へ中心寄りの斜め: `M3`, `M5` |
| **斜め後** | 盤上に1マス先がない → **反対側の外輪へワープ**（下記） |
| **縦横・後** | 盤外 → **反対側の外輪へワープ**（下記） |

**中輪**（例: `M4`）

| 種類 | 行き先の例 |
|---|---|
| **縦横** | 周回: `M3`, `M5`／レイ: `O4`（後）, `C1`（前） |
| **斜め前** | 中央寄りなど、盤面で定義される斜め隣（例: 該当マスがあれば `C1` 方向の斜め） |
| **斜め後** | 外輪寄りの斜め隣（例: `O3`, `O5` など） |

**中央**（例: `C1`・接続中輪は `M3`, `M4`, `M5`）

| 種類 | 行き先 |
|---|---|
| **縦横・横** | 内輪: `C0`, `C2` |
| **縦横・後** | 接続中輪の **正面3マス**: `M3`, `M4`, `M5` |
| **斜め後** | その3マスの **左右1マス**（中輪周回で外側にずれたマス）: **`M2`, `M6`** |
| **前・斜め前** | なし（これ以上内側へ進めない） |

一般式: 中央 `Ck` が接続する `M[3k]`, `M[3k+1]`, `M[3k+2]` に対し、**斜め後** は **`M[3k−1]`** と **`M[3k+3]`**（12マス輪で一周）。

#### ワープ（外輪のみ）

**レイ上の後** または **斜め後** を選び、1マス分 **盤外に出る** 扱いにできる（通常の縦横・斜め前とは別に、またはその代わりに選ぶ）。

| 項目 | 内容 |
|---|---|
| **着点** | **反対側の外輪** 1マス（レイ番号 `i` なら `O((i+6) mod 12)` など、半周ずらしで固定） |
| **できないこと** | 中輪・中央でのワープ／外輪の **横（周回）だけ** で盤外になる動き（外輪は閉じた輪） |

ワープの着点に相手がいれば **攻撃**、空なら **移動**。

---

### プレデター

**移動・攻撃（ジャンプ）**: いまいるマスから、下の **ジャンプ着点候補** のいずれかへ **1回で** 飛ぶ（途中のマスは飛び越え可能。味方のマスは着点不可）。

終点に相手がいれば **攻撃**（入って除去）。終点が空なら **移動**。

「前1＋横2」「後1＋横2」は **候補マスを決めるための考え方** であり、プレイでは **着点だけ** を選ぶ。いまいる **輪** ごとに候補が決まる（**後ろが盤外になる向きは候補に含めない**）。

#### 中央4マスの「反対側」

内輪 `C0`—`C1`—`C2`—`C3`—`C0` のうち、`Ck` の **反対側** は `C(k+2)`（4で一周）。例: `C1` の反対は `C3`。

#### ジャンプ着点（プレデター）

**外輪にいるとき**

- **後** は盤外になるため **使えない**（後系の候補はなし）。
- **前系（前1＋横2）のみ**: 同じレイの **中輪** へ1マス進んだあと、**中輪12マス輪** 上で **横に2マス**（左右）。
- **着点は中輪の2マスのみ**（最大2候補）。

**中輪にいるとき**

いまの中輪が接続している中央マスを `Ck` とする。

| 系 | 着点 | 考え方 |
|---|---|---|
| **前系**（前1＋横2） | **`Ck` の反対側の中央マス**（1マス） | 中心方向へ1相当のあと、内輪で横2相当 → **反対の中央** |
| **後系**（後1＋横2） | **外輪の2マス** | 同じレイの **外輪** へ1マス出たあと、**外輪** 上で **横に2マス**（左右） |

**合計3候補**（中央1＋外輪2）。`M3`〜`M5` がどれも `C1` に接続するため、前系の着点はどのマスからでも同じ **`C3`**。

**中央マスにいるとき**

- **前** はないため **前系は使えない**。
- **後系（後1＋横2）のみ**。中央は **接続中輪が3本** あるため、次のように候補を広げる（**中央マス用の特別ルール**）。

接続中輪を、レイ番号の小さいほうから `Ma`, `Mb`, `Mc` と呼ぶ（例: `C1` なら `M3`, `M4`, `M5`）。

1. **後1** 相当として、`Ma`・`Mb`・`Mc` の **それぞれ** を起点にみなす（3通り）。
2. 各起点から、**中輪12マス輪** 上で **横に2マス**（左右）。1起点あたり着点2つ。

**着点候補は最大6マス**（異なるマスが重なった場合は1つにまとめる）。

例（`C1` にいるとき）:

| 起点（後1） | 横2（左） | 横2（右） |
|---|---|---|
| `M3` | `M1` | `M5` |
| `M4` | `M2` | `M6` |
| `M5` | `M3` | `M7` |

→ 着点は `M1`, `M2`, `M3`, `M5`, `M6`, `M7` の **6マス**（`M3` は `M3` 起点の右と `M5` 起点の左で同じだが、選び方は2通りあっても着点は1つ）。

### ガーディアン

1ターンに **移動** または **攻撃** のどちらか一方。

#### 移動（いずれか一方）

いまいる **輪** 上で、次のパターンの **いずれか1つ**（途中マスは通過ルールに従い、**空でなければ進めない**）。

| 輪 | 選べる移動 |
|---|---|
| **外輪** | **前1**（レイ・中心側 → 中輪） **または** **横2**（外輪12マス輪）。**後** は盤外になるため **使えない**（ワープなし） |
| **中輪** | **前1**（レイ・中心側 → 中央） **または** **後1**（レイ・外周側 → 外輪） **または** **横2**（中輪12マス輪） |
| **中央** | **前** はない。**後1**（接続 **中輪3マス** のいずれか） **または** **横2**（中央4マス輪。多くの位置で反対の中央 `C(k+2)` に着く） |

**前1・後1・横2** は同時に使えない。1ターンでどれか1パターンだけ。

#### 攻撃

**いまいる輪** 上で、**横** 方向に **ちょうど2マス** 先のマスに相手がいるときだけ、そのマスへ **入って** 除去。

- **左右1マス先** には **攻撃できない**（隣接への取りはガーディアンの攻撃では不可）。
- 2マス先へ向かう **途中の1マス**（1マス目）にクリーチャーがいると攻撃できない（飛び越え不可）。

| 輪 | 攻撃の射程 |
|---|---|
| **外輪** | 外輪12マス輪上の横2 |
| **中輪** | 中輪12マス輪上の横2 |
| **中央** | 中央4マス輪上の横2（例: `C1` から `C3` へ飛び込み） |

**前** 方向への攻撃や、レイ上の2マス先攻撃はない。

---

### スカウト

**唯一、同一ターンで「移動」と「攻撃」の両方** ができる（順序は自由。**片方だけ**でもよい）。

| 操作 | 距離 | 備考 |
|---|---|---|
| **移動** | **直線2マス** のみ | **1マスだけの移動はできない** |
| **攻撃** | **縦横隣接1マス** | 斜め不可。相手マスへ入って除去 |

通過ルールは共通（途中に駒がいると移動不可）。味方のマスは着点不可。

#### 移動（直線2マス）

**縦横** の **一直線** にちょうど2マス（途中1マスを通る。斜めは使わない）。いまいる輪ごとに、使える直線は次のとおり。

**外輪**（例: `O4`）

| 種類 | 経路 | 着点の例 |
|---|---|---|
| **周回2** | 外輪12マス輪上で2マス | `O4` → `O6` または `O2` |
| **レイ2** | 同レイで外輪 → 中輪 → **その中輪の中央** | `O4` → `M4` → `C1` |

外輪からレイで2マス進めるのは **この内側への一直線だけ**（外→中→央）。外周側へ2マスはない。

**中輪**（例: `M4`）

| 種類 | 経路 | 着点の例 |
|---|---|---|
| **周回2** | 中輪12マス輪上で2マス | `M4` → `M6` または `M2` |

中輪ではレイ上は **1段で終わる**（中↔外・中↔央はいずれも1マス）ため、**直線2マスの移動で中央・外輪には着けない**。

**中央**（例: `C1`）

| 種類 | 経路 | 着点の例 |
|---|---|---|
| **内輪周回2** | 中央4マス輪上で2マス（途中は隣の中央1マス） | `C1` → `C3`（`C0` 経由または `C2` 経由） |
| **レイ2** | 中央 → 接続中輪の **いずれか1マス** → **そのレイの外輪** | `C1`→`M4`→`O4`、`C1`→`M3`→`O3`、`C1`→`M5`→`O5` など **3通り** |

中央の周回2は、ガーディアンと同様 **反対の中央マス** に着く。レイ2は接続3本それぞれで外周の別マスに出られる。

#### 攻撃（縦横1マス）

**盤面グラフの縦横隣接** にいる相手マスへ1マス入って除去（斜め不可）。

| いるマス | 攻撃できる隣接の例 |
|---|---|
| `O4` | `O3`, `O5`, `M4` |
| `M4` | `M3`, `M5`, `O4`, `C1` |
| `C1` | `C0`, `C2`, `M3`, `M4`, `M5` |

**移動2マスで着けなかった隣接**（例: 中輪から `O4` や `C1`）は、**攻撃1マス** で入れる。

#### 1ターンの流れ

1. **移動2** → **攻撃1**（別マスへ。移動の着点から隣接攻撃）  
2. **攻撃1** → **移動2**（攻撃後に別の直線2マス）  
3. **移動2** または **攻撃1** のみ  

移動と攻撃で **同じクリーチャーを2回動かす** のは、この2操作のこと（移動2のあと攻撃1など）。

> **バランス**: スカウトは他型より手数が多く強く感じられる可能性がある。初版はこのまま **プレイテスト（E）** し、必要ならルールを調整する。

---

## 始め方

1. 先攻・後攻を決める（Web 版ではランダムなど）。
2. **後攻** から交互に、自分のホーム半円の **連続4マス** に4体を置く（**どの型をどのマスに置くかは自由**）。先攻が最後に置く。
3. 先攻から手番開始。

---

## ゲームの終わり

いずれかのプレイヤーのクリーチャーが **0体** になったら終了し、相手の勝ち。

| スカウト | **移動は直線2のみ**／**攻撃は隣接1**／同一ターン両方可。**強さはプレイテスト後に調整可** |
| ブルート | **縦横斜め1**／外輪 **後・斜め後→反対外輪ワープ**／中央 **斜め後＝接続中輪の左右1** |
| ガーディアン | **前1／後1／横2**（外輪は後不可）／攻撃は **輪上横2** |
| ブルート | **縦横斜め1**＋外輪ワープ。中央も通常1マス |
| プレデター | 外輪→中輪2／中輪→反対中央1+外輪2／**中央→中輪最大6**（接続3×横2・飛び越え可） |
| 中央 | **4マス**の内輪。各マスは **中輪3マス** と接続。**前なし・後＝中輪3択・横＝隣接中央**（ボドパッ！独自の盤形） |
| チェイン攻撃・残り1体3手 | **採用しない** |
