# 5五将棋

## このゲームについて

5×5の盤で遊ぶ将棋です。本将棋と同じ駒の動きで、短時間に決着がつきやすいのが特徴です。

| 項目 | 内容 |
|---|---|
| 人数 | 2人 |
| プレイ時間 | おおよそ15分 |
| ジャンル | 将棋 |

## 勝利条件

次のいずれかで決着します。

- 相手の玉を**詰ます**（王手のまま合法手がなくなる）
- 相手の玉を**取る**（王手放置で玉を奪っても可）
- **千日手**（同一局面が4回）→ **後手の勝ち**

## 盤面の構成

- 5×5 のマス目
- 駒：玉・金・銀・角・飛・歩、および成駒（と・成銀・馬・竜）
- 桂・香は使用しない

## 始め方

手前を**先手（▲）**、奥を**後手（▽）**とし、点対称の配置から始めます。

```
   ５    ４     ３     ２     １
+-------------------+
|▽飛|▽角|▽銀|▽金|▽玉| 一 (後手)
|　　|　　|　　|　　|▽歩| 二
|　　|　　|　　|　　|　　| 三
| ▲歩|　　|　　|　　|　　| 四
| ▲玉| ▲金| ▲銀| ▲角| ▲飛| 五 (先手)
+-------------------+
```

先手から手番を始めます。

## 手番の流れ

1手につき、次のいずれかを1回行います。

1. **移動**：自分の駒を1つ動かす（相手の駒を取ることもできます）
2. **打ち**：持ち駒を空いているマスに1つ打つ

### 各駒の動き

本将棋と同じです。

| 駒 | 動き方 |
|---|---|
| 玉 | 周囲8方向に1マス |
| 金 | 前・前斜め・横・後ろ |
| 銀 | 前・前斜め・後斜め |
| 角 | 斜めに何マスでも |
| 飛 | 縦・横に何マスでも |
| 歩 | 前方1マス |

### 成り

銀・角・飛・歩が敵陣の**最奥1段**（先手なら1段目、後手なら5段目）に**入る**、または**そこから出る**移動をするとき、成る・成らないを選べます。

| 成駒 | 動き |
|---|---|
| と（歩）・成銀 | 金と同じ |
| 馬（角） | 斜め無限 ＋ 縦横1マス |
| 竜（飛） | 縦横無限 ＋ 斜め1マス |

歩が最奥段に入る場合は行き所がなくなるため、**強制的に成り**ます。

取った駒は持ち駒になります（成りは元の駒に戻ります）。玉は打てません。

## 打ち駒の制限

- **二歩**：同じ筋に、自分の未成りの歩を2つ並べて打てません
- **行き所のない駒**：最奥段に歩を打てません

## 千日手

同一の局面（盤面・持ち駒・手番）が**4回**出現したら、即座に**後手の勝ち**です。
