# 5五将棋

## このゲームについて

5×5の小さな盤で遊ぶ将棋のバリアントです。持ち駒の打ち込みと成りが特徴で、本将棋より短時間で楽しめます。

| 項目 | 内容 |
|---|---|
| 人数 | 2人 |
| プレイ時間 | おおよそ10〜20分 |
| ジャンル | 将棋 |

## 勝利条件

相手の玉を**詰ます**（王手のまま合法手がなくなる状態にする）と勝ちです。

自分の玉が取られる手は選べません。

## 盤面の構成

- 5×5 のマス目
- 駒の種類：玉・金・銀・角・飛・歩

## 始め方

### 後手（プレイヤー2・上側）

- 1段目：飛・角
- 2段目：金・銀・玉・銀・金
- 3段目の中央：歩1つ

### 先手（プレイヤー1・下側）

- 4段目の中央：歩1つ
- 残りの駒（金2・銀2・飛・角）は**持ち駒**として持ちます

プレイヤー1（先手）から手番を始めます。

## 手番の流れ

1手につき、次のいずれかを1回行います。

1. **移動**：自分の駒を1つ動かす（相手の駒を取ることもできます）
2. **打ち**：持ち駒を空いているマスに1つ打つ

### 各駒の動き

| 駒 | 動き方 |
|---|---|
| 玉 | 周囲8方向に1マス |
| 金 | 前・前斜め・横・後ろ（将棋の金将と同じ） |
| 銀 | 前・前斜め・後斜め |
| 角 | 斜めに何マスでも |
| 飛 | 縦・横に何マスでも |
| 歩 | 前方1マス |

### 成り

銀・角・飛・歩が**敵陣**（相手側の2段）に入ったとき、自動的に成り、金と同じ動きになります。

取った駒は持ち駒になります。玉は打てません。

## 打ち駒の制限

- **二歩**：同じ筋に、自分の未成りの歩を2つ並べて打てません。
- **行き所のない駒**：歩は最奥段に打てません。

## ゲームの終わり方

相手の玉が王手のまま合法手を持てなくなったら、自分の勝ちです。

## このサイト版の補足

- 打ち歩詰め・千日手などの細則は採用していません。
