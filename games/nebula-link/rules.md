# ネビュラ・リンク

## このゲームについて

21×21 の星雲盤に形状ブロックを置き、中央の星核を自分のホーム辺側に閉じ込めたプレイヤーの勝ち。2〜4人用のオリジナル配置ゲームです。

| 項目 | 内容 |
|---|---|
| 人数 | 2〜4人 |
| プレイ時間 | おおよそ10〜15分 |
| ジャンル | 盤面・配置 |

## 勝利条件

**自分のブロックだけの連結グループ**が次を満たしたら、その時点で勝ちです。

1. **ホーム辺**上に自分のマスがある（グループがホーム辺につながっている）。
2. **星核（中央1マス）**が、そのグループで閉じ込められている。

「閉じ込め」の判定：星核から、空マスと相手のブロックだけを通って盤の外周へ広げたとき、届く外周の辺が**自分のホーム辺だけ**になる状態。核のすぐ横を通る必要はなく、大回りで囲んでもよい。

得点はありません。共同勝利はありません（全員連続パス時のみ引き分け）。

## 盤面

- **21×21**（人数共通）
- **中央1マス**が星核（置けない）

### ホーム辺

| 人数 | プレイヤー | ホーム辺 |
|---|---|---|
| 2人 | 1 / 2 | 北 / 南 |
| 3人 | 1 / 2 / 3 | 北 / 東 / 西 |
| 4人 | 1〜4 | 北 / 東 / 南 / 西 |

3人のとき**南辺は中立**（どのプレイヤーのホーム辺でもない）。南辺上にも置けますが、勝利判定のホーム辺には含めません。

### 角のマス

外周の**角**は、交わる**両方の辺**に属します（例：4人で北東の角は北辺・東辺の両方）。

- **初回配置**や**ホーム辺に触れる**条件は、どちらかの辺に乗っていれば満たします。
- **星核の閉じ込め**判定でも、角からは両方の外周辺へ届く扱いです。
- プレイ画面では、角を**2色（または中立＋色）の分割**で表示します。

## ブロック

- 本家ブロックスより種類を絞った**ポリオミノ**（複数マスの形）を使用します。
- **単マス**はルーレットの対象外で、**いつでも**使えます。

### ルーレット

1. 手番の開始時、**ルーレットを回す**と形状プールから**ランダムに3種**が出ます。
2. プレイヤーは**3つのうち1つ**を選び、その形を1回置きます（ルーレット前でも単マスは使えます）。
3. 代わりに**単マス**を選んでもよいです。

## 置き方

1. 選んだ形は **0° / 90° / 180° / 270°** で回転できます。
2. 星核には乗せません。盤外にははみ出せません。
3. **初めて置くとき**：形の少なくとも1マスが**自分のホーム辺**上にあること。
4. **2手目以降**：
   - 形の少なくとも1マスが、**自分の既存ブロックの角**に接すること。
   - **自分の既存ブロックの辺には接しない**（角接触のみ）。

相手のブロックへの接触は、辺・角いずれもルール上の制限はありません（妨害になります）。

## 連結

- 同じプレイヤーのマスは、**8方向の隣り合い**（マスの辺または角で接している）で1つの**グループ**になります。
- 勝利は、このグループ単位で判定します。

## パス

- ルーレット3種と単マスの**いずれでも**合法な置き方がなければ**パス**できます。
- **全員が連続でパス**したら引き分けです。

## 手番

プレイヤー番号順（時計回り）。1手：ルーレット（または単マス）→ 置く or パス → 勝利判定。

## このサイト版の補足

- ルーレットの3つは重複しません。
- Web 版の実装は `lib/play/nebula-link.ts` と `components/play/NebulaLinkGame.tsx` です。
