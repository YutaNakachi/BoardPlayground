# 将棋

## 概要

| 項目 | 内容 |
|---|---|
| 人数 | 2人 |
| 時間 | 約30〜90分 |
| タイプ | 将棋 |

9×9 の盤で駒を動かし、持ち駒を打ち込んで相手の玉を詰めるゲームです。

## 目的

相手の玉を詰める（王手のまま合法手がなくなる）。

## 構成

- 9×9 盤
- 駒：玉・金・銀・桂・香・角・飛・歩（各プレイヤー標準配置）
- プレイヤー1（先手）は下側、プレイヤー2（後手）は上側

## 準備

本将棋の標準初期配置で駒を並べる。プレイヤー1（先手）から開始する。

## 手番

1. **移動**：自分の駒を1つ動かす（取りも可）
2. **打ち**：持ち駒を空きマスに1つ打つ
3. 駒の動き
   - **玉**：周囲8方向に1マス
   - **金**：前・前斜め・横・後ろ
   - **銀**：前・前斜め・後斜め
   - **桂**：前方に2マス進み左右1マス（桂馬跳び）
   - **香**：前方に何マスでも
   - **角**：斜めに何マスでも
   - **飛**：縦横に何マスでも
   - **歩**：前方1マス
4. **成り**：金以外の駒が敵陣（相手側3段）に入ったとき自動で成る
   - 歩・銀・桂・香 → 金と同じ動き
   - 角 → 角の動き＋縦横1マス
   - 飛 → 飛の動き＋斜め1マス
5. 取った駒は持ち駒（成りは元の駒に戻る）となり、いつでも打てる

## ゲーム終了

相手の玉が王手のまま合法手を持てなくなったら勝利。自分の玉を取られる手は選べない。

## 例外・タイブレーク

- **二歩**：同じ筋に自分の未成りの歩を2つ並べて打てない
- **行き所のない駒**：歩・香は最奥段、桂は最奥2段に打てない
- 千日手・持将棋などの引き分け条件は採用しない
- 打ち歩詰めの細則は採用しない
