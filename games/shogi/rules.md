# 将棋

## このゲームについて

9×9の盤で駒を動かし、取った駒を打ち込んで相手の玉を詰める2人用ゲームです。

| 項目 | 内容 |
|---|---|
| 人数 | 2人 |
| プレイ時間 | おおよそ45分 |
| ジャンル | 将棋 |

## 勝利条件

相手の玉を**詰ます**（王手をかけたまま、受けられる手がなくなる状態にする）と勝ちです。

自分の玉が取られる手は選べません。

## 盤面の構成

- 9×9 のマス目
- 駒：玉・金・銀・桂・香・角・飛・歩（各プレイヤー標準配置）
- プレイヤー1（先手）：手前（下側）
- プレイヤー2（後手）：奥（上側）

## 始め方

本将棋の標準初期配置で駒を並べ、プレイヤー1（先手）から手番を始めます。

## 手番の流れ

1手につき、次のいずれかを1回行います。

1. **移動**：自分の駒を1つ動かす（相手の駒を取ることもできます）
2. **打ち**：持ち駒を空いているマスに1つ打つ

### 各駒の動き

| 駒 | 動き方 |
|---|---|
| 玉 | 周囲8方向に1マス |
| 金 | 前・前斜め・横・後ろ |
| 銀 | 前・前斜め・後斜め |
| 桂 | 前方に2マス進み、左右1マス（桂馬跳び） |
| 香 | 前方に何マスでも |
| 角 | 斜めに何マスでも |
| 飛 | 縦・横に何マスでも |
| 歩 | 前方1マス |

### 成り

金以外の駒が**敵陣**（相手側の3段）に入ったとき、自動的に成ります。

| 駒 | 成ったあとの動き |
|---|---|
| 歩・銀・桂・香 | 金と同じ動き |
| 角 | 角の動き ＋ 縦横1マス |
| 飛 | 飛の動き ＋ 斜め1マス |

取った駒は持ち駒になります（成りは元の駒に戻ります）。いつでも打てます。

## 打ち駒の制限

- **二歩**：同じ筋に、自分の未成りの歩を2つ並べて打てません。
- **行き所のない駒**：歩・香は最奥段、桂は最奥2段に打てません。

## ゲームの終わり方

相手の玉が王手のまま受けられる手がなくなったら、自分の勝ちです。

## このサイト版の補足

- 千日手・持将棋などの引き分け条件は採用していません。
- 打ち歩詰めの細則は採用していません。
